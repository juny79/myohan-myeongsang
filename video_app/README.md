# 로컬 영상 생성 컨트롤러 (초기 단계)

## 지금 구현된 범위

- 기존 대시보드를 로컬에서 제공
- `/api/v1/health` 연결 상태 및 `nvidia-smi` GPU 정보 확인
- 프리셋별 검증 대상 Wan 모델 ID, 출처, 기준 VRAM을 명시
- 대시보드 선택 항목으로 선택 모델에 맞춘 3장면 스토리보드 명세 생성
- 쇼츠/롱폼 화면비·프리셋에 맞춘 타깃 설정 및 사람 검수용 장면 프롬프트 작성
- 작업 명세를 SQLite에 저장·목록 표시·대기 작업 취소
- Wan 공식 추론 코드를 호출하는 사전점검/짧은 생성 스모크 테스트 CLI 제공
- 모델 매핑·VRAM 게이트·명령 구성에 대한 표준 라이브러리 테스트 제공

**대시보드 API와 Wan 추론 워커의 자동 연결 및 FFmpeg 렌더링은 아직 구현되지 않았습니다.** 선택 프리셋은 해당 Wan 모델 명세를 표시합니다. 실제 테스트는 GPU 호스트에서 별도 CLI를 실행해야 하며, 시작 이미지·체크포인트·CUDA 환경이 필요합니다. 결과 경로와 실행법은 [Wan 모델 검증 안내](./MODEL_VALIDATION.md)를 참고하세요.

## 실행

Python 3.10 이상이 있는 프로젝트 루트에서 실행합니다. 추가 Python 패키지는 필요하지 않습니다.

```powershell
py video_app/server.py
```

Windows에서 `py` 런처를 사용할 수 없으면:

```powershell
python video_app/server.py
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 같은 포트에서 기존 서버가 이미 실행 중이면 먼저 기존 서버를 종료하거나 `video_app/server.py`의 `PORT`를 변경하세요. 종료는 실행 중인 터미널에서 `Ctrl+C`로 합니다.

## 확인 주소

- 대시보드: `http://127.0.0.1:8765/`
- 상태/GPU 확인: `http://127.0.0.1:8765/api/v1/health`
- 작업 목록: `http://127.0.0.1:8765/api/v1/jobs`

작업 DB는 `runtime/video_jobs.sqlite3`에 만들어집니다. DB는 로컬 임시 운영 데이터이며 Git에 커밋하지 않습니다.

## 테스트

프로젝트 루트에서 표준 라이브러리 테스트를 실행합니다.

```powershell
py -m unittest video_app.test_manifest video_app.test_wan_runner -v
```
